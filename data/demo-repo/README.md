# PrivPass Demo Leak Repository

This repository is intentionally seeded with **fake, non-functional credential strings** for a hackathon scan demo. The goal is to show detection, confidence, redaction, and remediation. No secret here should be used anywhere.

Demo story:
1. Upload this ZIP to SecretGuard.
2. Review CRITICAL/HIGH findings.
3. Inspect the explanation for each finding.
4. Move findings from DETECTED → TRIAGED → CONTAINED → ROTATED → VERIFIED.
5. Use the Command Center to review aggregate posture.
