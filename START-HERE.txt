PRIVPASS SHIELD 6.2.0 — START HERE

1. Extract this folder to a normal Windows folder.
2. Double-click START-PRIVPASS.bat.
3. Open the URL printed by the launcher (normally http://localhost:8000 - use localhost so passkeys work).
4. Open Demo Center for demo credentials.
5. Demo user: user@privpass.local / PrivPass!Demo#2026-User
6. Open Vault, sign in as the demo user, unlock the vault with the same account password, then choose Add demo logins.
7. For SecretGuard, use demo-assets/PrivPass-Demo-Leak-Repo.zip.

Security notes:
- HIBP sees only the first five SHA-1 characters during the browser-side range lookup.
- Saved vault logins are AES-GCM ciphertext and are not readable in the admin console.
- Forgot-password recovery intentionally clears the zero-knowledge vault because the server does not have a recovery key.
