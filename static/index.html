(03)How your password stays yours
  1. 01

    Hashed in your browser

    Web Crypto turns the password into a SHA-1 digest locally. The plaintext never touches the network.

  2. 02

    Only five characters leave

    The first 5 hex characters go to HIBP. Hundreds of breached hashes share every prefix, so HIBP cannot tell which one is yours.

  3. 03

    Every matching suffix comes back

    Roughly 800 suffixes per prefix, padded with decoys so even the response size gives nothing away.

  4. 04

    The match happens here

    Your browser compares suffixes locally. A breached password is refused with a server-issued ticket.

    AI LAB

    Models that never see a secret.

    Three models trained and evaluated for this project, plus generative AI for explanation and action. Every AI request passes a redaction guard; findings reach the model only as masked snippets.

    Checking…—
    01 · SECRET CLASSIFIER

    LightGBM on 35 code features

    Decides whether a string literal is a hardcoded credential, using entropy, character mix, variable name, file path and context. Explains every score with SHAP contributions.

    02 · NEURAL PASSWORD MODEL

    Char-GRU + Monte Carlo guess numbers

    Estimates how many guesses an attacker needs (Melicher et al., USENIX Security 2016). Runs as 217 KB of int8 weights in the browser.

    03 · LOGIN ANOMALY DETECTOR

    Isolation Forest on sign-in windows

    Unsupervised: learns normal sign-in behaviour per IP and 5-minute window, then flags credential stuffing, brute force and account enumeration.
